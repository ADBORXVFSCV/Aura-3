# Project Aura: Intent-Driven Cognitive Agent & Behavioral Analysis Engine

An autonomous, on-device AI agent designed to run natively on resource-constrained mobile hardware (specifically optimized for the Samsung Galaxy A03s). This system operates with a dedicated, persistent personality, orchestrating complete device automation while concurrently engaging in hyper-realistic human interactions. 

The core research objective is to analyze interpersonal communication, extract deep psychological patterns, detect structural cognitive/linguistic errors in natural human speech, and pipe these insights into an on-device training loop to uncover emergent behavioral models.

---

## 👁️ System Overview

This project shifts away from traditional, rigid monolithic command architectures. Instead, it introduces a highly lightweight, **Intent-Driven System Architecture** optimized for low-overhead deployment. It functions simultaneously as an executive device controller and a psychological data collection node.
